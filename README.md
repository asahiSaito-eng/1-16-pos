# ☕ 1-16 カフェ 文化祭レジシステム (Smart POS & Kitchen System)

文化祭の模擬店（カフェ・スイーツ・クレープ・ドリンク）に特化した、**Firebase Realtime Database & Vercel 対応** のリアルタイムPOSレジ＆厨房管理Webアプリケーションです。

---

## 🌟 主な機能と特徴

### 1. 🔥 Firebase Realtime Database リアルタイム一元管理
- **ミリ秒単位の超高速同期**: 会計が入った瞬間、別のiPad、厨房モニター、売上分析画面へ即座に反映されます。
- **設定画面から簡単接続**: Firebaseコンソールの設定（JSONやfirebaseConfig）を設定画面に貼り付けるだけで完了。
- **オフラインレジリエンス**: ネット接続が一時的に途切れても、Firebaseの組み込みキャッシュによりローカルで動作し続け、再接続時に自動同期されます。
- **CSV一括エクスポート**: 売上分析画面から、いつでもワンクリックでExcelやGoogleスプレッドシートで開けるUTF-8 BOM付きCSVをダウンロード可能。

### 2. ▲ Vercel デプロイ対応
- `vercel.json` 完備。GitHubと連携するか、`npx vercel` を実行するだけで即座に世界中・学校中からアクセス可能なURLが発行されます。
- 環境変数（`VITE_FIREBASE_...`）またはアプリ内の設定画面のどちらからでもFirebaseを設定可能。

### 3. 🛒 レジ会計・お釣り自動計算 (POS Register - F1)
- **タブレット＆PC両対応**: タッチ操作しやすい大きなボタン ＆ PCキーボードショートカット（テンキー入力、Enterで確定）。
- **リアルタイムお釣り計算**: `+1,000円`、`+5,000円`、`+10,000円`、`ちょうど` のクイックお預かりボタン。
- **在庫数カウント・売り切れ表示**: 残数ゼロで自動「SOLD OUT」バッジ、二重販売を防止。
- **引換券チケット発行**: 会計完了時に「#001」等の呼び出し番号チケットを発行（紙吹雪演出＆印刷対応）。

### 4. 🍳 厨房・受渡モニター画面 (Kitchen Display - F2)
- **リアルタイムカンバン**: 「🍳 調理中 / 準備中」➔「🔔 お渡し可能（呼出中）」➔「✅ 受渡完了」をワンタップで進行。
- **お客様用 呼出特大ディスプレイ**: モニターやプロジェクター等にお客様向けに出来上がり番号を大きく掲示可能。
- **ピンポーン♪新着通知音**: レジで注文が入ると厨房画面で通知音が鳴ります。

### 5. 📊 売上集計・分析ダッシュボード (Analytics - F3)
- 総売上、総客数、平均客単価、総販売個数をリアルタイム集計。
- **時間帯別 売上推移グラフ** (Chart.js) ＆ **カテゴリ別売上シェア**。
- **商品別 人気ランキング TOP 5**。
- **CSVエクスポート**: GoogleスプレッドシートやExcelでそのまま開けます。

### 6. 🍰 商品・メニュー管理 (Menu Editor - F4)
- クレープ、ワッフル、タピオカ、ドリンクなどのメニュー追加・編集・削除。
- 価格変更、初期在庫設定、絵文字アイコン変更。
- 「+10」「+50」「−5」のクイック在庫補充。

## 🚀 起動方法 & デプロイ

### ローカル開発サーバー起動
```bash
npm run dev
```
ブラウザで [http://localhost:5173/](http://localhost:5173/) を開きます。

### Vercelへのデプロイ
```bash
# Vercel CLIでデプロイする場合
npx vercel

# または GitHub リポジトリに push して Vercel にインポート
```

## 🔥 Firebase Realtime Database のセットアップ手順（約3分）

1. [Firebase Console](https://console.firebase.google.com/) でプロジェクトを作成します。
2. 左メニューの「構築」➔「Realtime Database」を選択し、「データベースの作成」を押します。
3. セキュリティルールで**「テストモードで開始」**（読み書き許可）を選択して作成します。
4. プロジェクト設定の「全般」➔「マイアプリ」で「ウェブ（</>）」を追加し、表示された `firebaseConfig` をコピーします。
5. 本アプリの **「⚙️ 設定・同期 (F5)」** 画面の貼り付け枠にペーストして「Firebase設定を保存して接続」を押すだけで完了です！
